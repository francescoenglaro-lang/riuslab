## Installare

1. Scarica il file `.dmg` dell'app dalla pagina delle versioni e aprilo.
2. Trascina l'app sulla cartella Applicazioni (se c'è già una versione precedente, scegli «Sostituisci»: le impostazioni restano).
3. Al primo avvio macOS dice che non può verificare lo sviluppatore: Impostazioni di Sistema › Privacy e sicurezza › «Apri comunque» (una volta sola).

Serve un Mac con chip Apple e macOS 26 o successivo.
